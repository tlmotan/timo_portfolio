# Timothy Tan · Portfolio

Personal portfolio site: projects, experience and blog.

It is a plain static site (no build step): `index.html`, `styles.css` and `main.js`.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

## Deploy

Hosted on [Vercel](https://vercel.com). Import this repository in Vercel with the framework preset set to **Other**; every push to `main` redeploys. To use a custom domain, add it under the project's **Settings → Domains** and set the DNS records Vercel shows.
